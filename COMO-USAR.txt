FINE FORM — README VISUAL

O README.md e a pasta assets formam uma única apresentação. Copie os dois juntos.

PERFIL DA ORGANIZAÇÃO
No repositório público .github, coloque README.md e assets dentro da pasta profile:
profile/README.md
profile/assets/fine-form/...

PERFIL PESSOAL OU README DE REPOSITÓRIO
Coloque README.md e assets na raiz do repositório.

Depois envie os arquivos ao GitHub e confira a prévia do README.
As versões clara e escura são selecionadas pelo tema do visitante. As versões para celular adaptam a composição para telas menores.

Os contatos são clicáveis, incluindo o card Fine Form Care. Não há endereço, instruções técnicas do sistema, banco ou deploy nesta apresentação.

As versões SVG originais e PNG acompanham o pacote. Os PNGs são utilizados no README para exibição consistente.

A capa escura tem uma animação suave. A versão estática é usada para quem prefere movimento reduzido.
