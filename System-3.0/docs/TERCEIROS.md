# Assets e dependências

O pacote preserva as fotos, fontes e logo do projeto Fine Form original. Créditos das fotos também aparecem no modal de Créditos do site. Imagens editoriais não representam veículos efetivamente atendidos pela Fine Form.

- Logo: arquivo original fornecido para a Fine Form, `dist/assets/logo-original.png`.
- Fontes: Manrope e Barlow, com licenças OFL em `dist/assets/fonts/`.
- Efeitos React Bits usados: Stack, ScrollVelocity e BorderGlow. Licença em `src/react-bits/LICENSE.md` e `dist/assets/react-bits.LICENSE.txt`.
- FolderFloat: adaptação independente do gesto de pasta do projeto anterior.
- Bundle React: avisos de terceiros em `dist/assets/studio-react.mjs.LEGAL.txt`.
- Dependências npm: React, React DOM, Motion, esbuild, Wrangler, Miniflare e jsdom; versões fixadas no package-lock. As licenças desses pacotes acompanham a instalação npm.

Não há efeito Ferrofluid no código do site. Esta entrega não muda a titularidade dos arquivos originais nem atribui uma nova licença geral ao projeto da Fine Form.
