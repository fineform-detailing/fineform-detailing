# Vehicle views

Ferrari 458 Italia by vicent091036, distributed with the Three.js r180 car example:
https://threejs.org/examples/webgl_materials_car.html
https://sketchfab.com/models/57bf6cc56931426e87494f554df1dab6
https://cdn.jsdelivr.net/gh/mrdoob/three.js@r180/examples/models/gltf/ferrari.glb

Views are rendered from one model, using the camera positions in render-views.py. Eight external views support horizontal dragging; five treatment views reveal the relevant regions, including the actual cabin geometry. The website uses the same pre-rendered views as its approved preview so it works without a WebGL context. The heavier rotation sheet loads only when the visitor interacts with the car.
